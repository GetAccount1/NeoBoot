
# NeoBoot

**NeoBoot** is a modern, Rust-based bootloader designedalternative to traditional bootloaders like GRUB, U-Boot, and others.

> **⚠️ This is beta version, some other PC or laptop have error.**
> NeoBoot is currently under active development. Some features may not function as expected.


- **Written in Rust** - Memory safety and high performance
- **Controller Support**
  - DualSense (PlayStation 5) Controller
  - Xbox Controller
  - **Steam Controller support coming soon**
- **Theming** (In Progress)
  - Custom theme background **(Coming soon)**
- UEFI support?

## Getting Started

```bash
# Clone the repository
git clone https://github.com/GetAccount1/NeoBoot/
cd neoboot

# Build
cargo build --release
```
